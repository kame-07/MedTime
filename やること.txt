【ここからはご自身で行うこと】
================================================================

--- 手順1. コードをGitHubに送る ------------------------------

  1-1. リポジトリを「公開」か「非公開」どちらにするか決める
       (トークン等の秘密情報はコードに含めていないので公開でも
       問題ありませんが、迷ったら「非公開」で構いません)

  1-2. GitHubに新しいリポジトリを作る
       https://github.com/new
       → リポジトリ名を決めて「Create repository」

  1-3. Claudeに「公開/非公開どちらにするか決めた」と伝えてください。
       決まれば、ローカルのコードをそのリポジトリに送るところまで
       Claudeが代わりに行います。


--- 手順2. Renderのアカウントを作る ---------------------------

  2-1. https://render.com/ にアクセスし、
       「Get Started」からGitHubアカウントで登録する
       (連携すると手順3が楽になります)

  2-2. クレジットカード情報を登録する
       (Starterプランを使うために必要)


--- 手順3. Web Serviceを作成する -------------------------------

  3-1. Renderの画面で「New +」→「Web Service」
  3-2. 手順1で作ったGitHubリポジトリを選択
  3-3. 以下のとおり設定する

       Build Command   pip install -r requirements.txt
       Start Command   (Procfileがあるので空欄でよい)
       Instance Type   Starter を選ぶ
                       (Freeは常時起動できないため選ばないこと)


--- 手順4. 環境変数を設定する -----------------------------------

  Renderの「Environment」タブで、.env に書いた内容と
  同じものを1つずつ登録する。

    CHANNEL_ACCESS_TOKEN   = (LINEのチャネルアクセストークン)
    CHANNEL_SECRET         = (LINEのチャネルシークレット)
    TIMEZONE               = Asia/Tokyo
    RETRY_INTERVAL_MINUTES = 5
    TIMEOUT_BEHAVIOR       = immediate
    MAX_RETRY_COUNT        = 0
    DATA_FILE              = /var/data/schedules.json

  ※ DATA_FILE は手順5で作るディスクの場所と合わせるため、
     必ず /var/data/schedules.json にしてください。


--- 手順5. 永続ディスクを追加する(重要・忘れると危険) -----------

  これを忘れると、Renderが再起動するたびに登録した時刻データが
  すべて消えてしまいます。

  5-1. Web Serviceの「Disks」タブを開く
  5-2. 「Add Disk」をクリック
  5-3. Mount Path に  /var/data  と入力
  5-4. Size は 1GB のままでよい


--- 手順6. デプロイ完了後、Webhook URLを更新する -----------------

  6-1. デプロイが終わると
       https://(サービス名).onrender.com
       という固定のURLが発行される

  6-2. LINE Developers Console →「Messaging API設定」タブを開く

  6-3. Webhook URL を書き換える

       https://(サービス名).onrender.com/callback

  6-4. 「更新」→「検証」を押して「成功」と表示されるか確認する


--- 手順7. ローカルの後片付け -------------------------------------

  Renderで動作確認が取れたら、以下はもう不要になるので終了してよい。

    ・ start.bat のウィンドウ(ボット本体)
    ・ cloudflared のウィンドウ(トンネル)
